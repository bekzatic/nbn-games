Games bring us together

Resize the browser window. The font size of the headings and paragraphs on this block changes with CSS media queries: small on a phone, medium on a tablet and large on a desktop screen.

Why the font size changes

On a narrow phone screen a huge heading would take the whole screen, while on a wide monitor small text is hard to read. With media queries we choose a comfortable size for each device.
